# 标准封面修改平台（固定模板批量版）

Windows 用户可直接双击 `启动.bat`。首次启动会自动安装所需组件（包括原 DOC 直改所需的 `pywin32`）。也可在命令行运行：

```bash
pip install -r requirements.txt
streamlit run app.py
```

打开浏览器显示的网址即可使用。平台内置固定标准封面模板，不需要上传模板文件。

## Render 公开部署

本项目已包含 `Dockerfile` 与 `render.yaml`。将整个项目上传到 GitHub 仓库后，在 Render 中选择 **New + → Blueprint** 并连接该仓库即可部署；完成后将服务访问权限设为 Public。服务器内已安装 LibreOffice，用于处理 DOC 与 DOCX。

- 单个生成：上传一个待修改 DOCX，确认识别信息后下载。
- 批量生成：拖放 ZIP、RAR、7Z、TAR、TAR.GZ/TGZ、TAR.BZ2/TBZ 或 TAR.XZ/TXZ 与 Excel 对照表；输入是什么压缩格式，输出即保持相同格式及扩展名。固定读取 B 列标准名称、P 列起草单位、Q 列主要起草人、R 列起草人与起草单位对应情况。严格识别目标 DOCX：优先文件名含“标准文本”；若没有，则仅接受文件名与母文件夹标准题目完全一致的 DOCX，并复核其封面题目及 ICS/CCS 或标准编号特征。多个候选时会跳过并提示，其他内容与目录结构保持原样。
- 批量完成后会显示未修改母文件及原因；Excel 中存在、但 ZIP 中未找到的标准直接忽略。
- ZIP 可以含一个最外层总目录；系统会自动跳过总目录，在任意层级查找与 Excel B 列完全一致的标准母文件夹。
- Excel 可含多个工作表与顶部说明行；系统仅读取同时具有 B列“标准名称”、P列“起草单位”、Q列“起草人”的数据表。
- 批量目标不再按“文件名含标准”宽泛识别。`2026 - XX - XX` 等日期会从待修改文件的六个日期窗体域原样保留；国际一致性标识窗体域保留为空白可编辑状态。
- 支持“目次”“目录”“前言”及首页分节符等封面结束结构，找不到“目次”的标准文件也可安全处理。
- 批量生成可统一填写第一协会和归口单位；第一协会默认“西安市质量与标准化协会”，归口单位默认“青海省标准化协会”，均可修改。两个协会会同步写入封面协会窗体域，以及前言中独立的“本文件由……提出。”“本文件由……归口。”两行。
- 可统一填写“标准编号前缀”（如 `T/QAS`）；每个母文件会保留原序号和年份，并同步修改标准文本封面、页眉、正文及所有子文件中完全相同的标准编号。
- 子文件规则：传统立项建议书填写项目申请单位、归口单位和共同发起单位；新版立项建议书填写“第一起草单位”为指定归口单位、“参加起草单位”为 Excel P 列起草单位；两类立项建议书均可指定负责人（默认“刘伟朝”），仅替换原负责人姓名，并清空联系电话及 E-mail/邮箱右侧填写内容；投票单标题也统一使用该归口单位。编制说明填写负责起草单位，并且只重建表内明确标有“标准起草人”的起草人表，不会改动“参与起草单位”表；人员数据固定插入在“标准起草人”行和“序号/姓名/单位/职务(职称)”表头行之后；意见汇总处理表填写标准编号和负责起草单位；审查专家签字表决结果汇总表同步标准编号。
- 输出压缩包会保留原有资料目录，但会自动移除与目录同名的 0 字节空白占位文件，避免出现文件夹与同名空白文件成对显示。
- 输出压缩包会删除每个已识别标准母文件夹内的所有 PDF 子文件（如“标准文本.pdf”）；没有 PDF 时直接跳过，母文件夹外的 PDF 保留。
- 对意见汇总处理表等子文件，只替换目标值所在的原文字段：不合并整段 run，不改动原有制表符、换行、段落间距、表格列宽或其他文字格式；因此生成结果与原文件版式保持一致。
- RAR 输入在部分电脑上需要已安装 7-Zip、WinRAR 或 unrar 工具；RAR 同格式输出必须安装 WinRAR，并将 `rar` 命令加入系统 PATH。若条件不满足，平台会提示，不会擅自转成 ZIP。
- 子文件支持 DOCX 直接修改；其他类型 DOC 会先自动转换为 DOCX、修改后再还原为原 DOC 格式。转换器优先使用 LibreOffice；未安装 LibreOffice 时会自动尝试电脑中的 Microsoft Word 或 WPS。三者均未安装时，DOC 无法在不破坏版式的前提下修改。不可编辑或扫描型 PDF 会保留原文件并提示原因。
- **原始 DOC 的意见汇总处理表不再允许转换中转。**它必须由已安装的 Microsoft Word 或 WPS 直接打开、就地替换并保存，以保留原页面、表格、换行和字体格式。若没有检测到直改组件，平台会提示该文件失败，不会生成版式已改变的错误文件。启动前请关闭正在打开的 Word/WPS 文档，并使用 `启动.bat` 完成组件安装。
- 原始 DOC 的意见汇总处理表会同时替换完整标准编号及其前缀；即使编号在表格单元格中被换行拆开，也会与标准文本的标准编号保持一致。
- 批量处理会自动忽略并移除 Word/WPS/LibreOffice 产生的 `~$`、`.~` 临时锁定文件，避免把它们作为 DOCX 解析而报“File is not a zip file”。
